# 03_dog_stand — 四足机器人站立控制仿真

基于 MuJoCo 的四足机器狗 PD 控制站立仿真。实现从趴姿到稳定站立的两阶段平滑站起（先抬膝、再立身），支持阻尼和站立两种模式键盘切换。

## 功能特性

- 阻尼模式：关节施加弱阻尼，机器人平稳趴下落地，抑制落地后的自由震荡
- 两阶段站立：
  1. 收膝阶段：大腿前摆加小腿伸直，膝盖沿以脚掌为圆心的圆弧抬起，腿折叠成 `<` 形支撑，低重心稳底盘
  2. 立身阶段：压髋升重心，平滑过渡到最终半蹲站立姿态
- 平滑插值：目标角度按固定步长逐帧逼近，到位后自动锁定，消除抖动
- 键盘交互：运行中实时切换模式

## 快速开始

```bash
cd 03_dog_stand
python main.py
```

启动后机器人以阻尼模式自然趴下，等待按键。

## 操作说明

- 空格键：切换至站立模式，从当前趴姿两阶段站起
- D 键：切换至阻尼模式，关节进入弱阻尼模式，机器人平稳趴下

## 核心实现

### 控制律

采用 MIT 风格 PD 控制：

```
tau = KP * (q_des - q) + KD * (0 - dq)
tau = clip(tau, -TAU_MAX, TAU_MAX)
```

### 关节布局

共 12 个关节，4 条腿各 3 个关节（侧摆、髋、膝），顺序如下：

- 前左 FL：侧摆、髋、膝，对应索引 0、1、2
- 前右 FR：侧摆、髋、膝，对应索引 3、4、5
- 后右 RR：侧摆、髋、膝，对应索引 6、7、8
- 后左 RL：侧摆、髋、膝，对应索引 9、10、11

左右腿镜像对称。

### 两阶段站起状态机

机器人初始处于阻尼模式，平稳趴下。按下空格键后进入站立模式，依次执行两个阶段：

1. 收膝阶段：目标角度为 RETRACT_Q，膝盖抬起，腿折叠成 `<` 形，身体保持低重心
2. 立身阶段：收膝角度到位后自动切换，目标角度为 STAND_Q，压髋升重心到最终半蹲站立

站立过程中按下 D 键可随时切回阻尼模式，机器人释放关节趴下。

## 关键参数

- KP = 35：比例增益，越大发力越猛
- KD = 4：阻尼增益，抑制速度和过冲
- TAU_MAX = 33.5：单关节最大力矩限幅
- SIMULATE_DT = 0.002：物理仿真步长，500 Hz
- INTERP_STEP = 0.005：站立插值步长，越小动作越慢
- STAND_Q：髋角正负 0.8，膝角负正 1.25，最终站立目标角度，单位弧度
- RETRACT_Q：髋角正负 1.0，膝角负正 1.45，收膝过渡目标角度，单位弧度
- DAMPING_KD = 0.5：阻尼模式专用阻尼系数，仅用于抑制关节速度，不提供定位力矩

角度单位为弧度，正负号对应左右腿镜像。

## 已知限制

- 仅实现站立和趴下，无行走、转向等步态控制
- 仅在平地场景验证，未测试斜坡或不平地面
- 目标角度为开环插值，无质心位置反馈，姿态稳定性依赖参数匹配
- 阻尼模式下关节施加弱阻尼，无主动定位力矩，落地后需等待稳定再切换站立
